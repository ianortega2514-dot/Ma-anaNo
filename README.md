# MañanaNo

App para preparar trámites y saber si vas a volver mañana.

Hecha con React + TanStack Start + Vite.

## Cómo desplegar en Vercel

1. Sube este repositorio a GitHub (ya lo tienes).
2. Ve a [vercel.com](https://vercel.com) e inicia sesión con GitHub.
3. Importa el repositorio `Ma-anaNo`.
4. Dale a Deploy.

Vercel debería detectar automáticamente el proyecto.

## Desarrollo local

```bash
npm install
npm run dev
```

La app corre en http://localhost:8080

## Notas

- Auth está desactivado por defecto.
- No requiere base de datos para funcionar.
- Es una PWA: se puede agregar a la pantalla de inicio del móvil.
